# 孙程摄影作品集

原创构建的摄影作品集与本地管理后台。前端使用 Vite 和原生 JavaScript，后端使用 Express。无需数据库或第三方服务。

## 启动

需要 Node.js 20.19+ 或 22.12+（当前使用 24）。在仓库目录执行：

```sh
npm ci --cache /tmp/portfolio-npm-cache
npm run build
npm start
```

本机浏览器访问 `http://localhost:3000`；后台为 `http://localhost:3000/admin`。服务绑定 `0.0.0.0`，默认端口 3000，可通过 `PORT` 修改。这些地址是本地使用说明，并非云端公开预览地址。

首次启动自动生成随机管理密码，保存在 `.data/admin-initial-password.txt`。请在本机用编辑器查看，勿分享、提交或记录到日志。后台仅需密码登录。可执行 `npm run admin:reset` 重新生成密码，然后重启服务使现有登录失效。

## 管理功能

- 上传 JPG、PNG、WebP 照片，单张最大 12MB
- 新增与删除作品分类（使用中的分类需先清空作品）
- 编辑标题、分类和简介
- 发布、下架、永久删除作品与照片
- 未发布照片仅在管理员登录后可读取
- 前台支持分类筛选和作品详情大图，手机端适配

新上传作品默认保存为草稿。勾选发布后才会展示在前台。前台初始不提供虚构作品；首页装饰图是 CSS 抽象光影，并非摄影作品。联系方式尚未提供，暂时使用已有 GitHub 联系入口。

## 开发与测试

在两个终端分别运行：

```sh
npm run server
npm run dev
```

Vite 将 `/api` 和 `/media` 代理至端口 3000。修改后端端口时需同步调整 `vite.config.js`。

```sh
npm test
npm run build
```

集成测试在独立临时目录验证登录、上传、文件类型检查、编辑、分类、发布与下架权限、重启持久化、删除及退出登录。

## 数据与备份

所有持久数据在 `.data/`：作品与分类在 `content.json`，照片在 `uploads/`，管理密码哈希在 `admin.json`。该目录已被 Git 忽略。停服后备份整个目录，可恢复作品与账户；不要仅备份代码。删除作品会永久删除照片文件。

当前面向单机本地运行：登录会话保存在内存中，重启需重新登录；内容采用 JSON 文件保存，不支持多进程同时写入。若将来发布公网，需要 HTTPS、持久化磁盘、共享会话存储与适合部署规模的数据存储。本次未发布公网。

## 目录

- `src/`：前台与管理后台页面、样式
- `server/app.js`：认证、作品 API、文件上传与静态服务
- `server/reset-password.js`：本机密码重置
- `test/server.test.js`：完整 API 流程测试
- `dist/`：构建产物（已忽略）
